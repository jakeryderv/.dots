# Approved sources

Use these public webpages as the default, preferred sources. Pass the relevant
domains to `web_search` via `domainFilter`. If an approved source does not cover
a fact, you may use another public source but must label it `(unapproved
source)` in the report's Sources list.

## Trust-level reminder

- **Publisher-stated** (provider docs): authoritative for pricing, context
  window, modalities, availability.
- **Third-party measured** (Artificial Analysis, benchmark sites): use for
  latency, throughput, and benchmark scores; report numbers exactly as stated.
